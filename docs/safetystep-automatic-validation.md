## 구현 결과

사고 접수 후 차량 제어·음성 응답·사건 전파를 각각 시작한다. 응답/이동 가능 질문에서 하차 이후까지 좌석도와 비트박스 현황판을 유지한다. 다음·정차 확인·경로 확인·안내 완료 버튼으로 정상 흐름을 넘기지 않는다. 움직일 수 있는지에 대한 사용자 보고와 신선한 기어·속도를 함께 확인하고, 안전하게 내릴 수 있을 때 이동하도록 안내한다. 관측 좌석이 모두 비면 차량 복귀/IVI 조작을 요구하는 버튼을 없앤다.

- 비상등: 사건별 시도와 명령 수를 디스크에 먼저 기록. 앱 재시작이나 테마 변경으로 재전송하지 않는다.
- 상태 판정: SWITCH=1과 실제 STATE=1을 함께 확인한다. 이 에뮬레이터의 STATE는 500ms 점멸 위상이다. 150ms 간격의 제한된 관측 창을 사용한다. 스위치만으로 성공 체크하지 않는다.
- 트렁크: 후방 충돌/상황 불명/이동 중/현재 속도 미확인에서 개방 보류. 전방 충돌 + 이동 가능 응답 + 신선한 P·정지 + 명시적으로 확인된 후방 공간에서 SDK 개방을 1회 요청한다. 실제 열림이 관측되면 체크한다. 후방 공간은 이번 재현 조건 입력이며 센서 판별을 입증하지 않는다.
- 좌석: 처음부터 빈 좌석과 이번 사건에서 비워진 좌석을 구분. 운전석 하차 후 동승자 잔류 유지. 지원 좌석이 누락되거나 오래된 값이면 전원 하차로 처리하지 않는다.
- 전파: 동의·연결·전송 대기 상태를 반영한다. 전원 좌석 비움이 도로 위험 사건을 종료하지 않는다.

## 음성 포함 편집본 — 2026-11-15
